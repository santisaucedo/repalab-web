# RepaLab — sitio web

Landing comercial de [repalab.com.ar](https://repalab.com.ar).

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Salida en `dist/` — deployable en Cloudflare Pages o Vercel.

La app (login / PWA) va en DigitalOcean: `app.repalab.com.ar`.
